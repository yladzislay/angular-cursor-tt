# План разработки: Функциональная таблица данных

Этот план описывает шаги по созданию функциональной таблицы данных в соответствии с требованиями, изложенными в `task-requirements-rus.md`.

## 1. Настройка проекта и базовые компоненты

*   **1.1. Инициализация проекта:**
    *   Создать новый Angular проект с помощью Angular CLI (`ng new`).
    *   Настроить базовую структуру проекта (модули, папки для компонентов, сервисов).
*   **1.2. Сервис данных:**
    *   Создать сервис (`DataService`) для инкапсуляции логики работы с данными.
    *   Реализовать в сервисе метод для получения данных из `data.ts`.
    *   Имитировать асинхронный запрос с использованием RxJS (`Observable`, `of`, `delay`) со случайной задержкой.
    *   Определить интерфейс (`interface`) для типизации объектов данных.
*   **1.3. Основной компонент таблицы:**
    *   Создать компонент (`DataTableComponent`) для отображения таблицы.
    *   Подключить `DataService` для получения данных.
    *   Отобразить базовую структуру таблицы (`<table>`) с заголовками и строками данных.

## 2. Реализация основной функциональности

*   **2.1. Сортировка:**
    *   Добавить обработчики кликов на заголовки колонок (`<th>`).
    *   Реализовать логику сортировки данных (по возрастанию/убыванию) в `DataService` или непосредственно в компоненте.
    *   Обновлять отображение таблицы после сортировки.
    *   Добавить визуальную индикацию активной колонки сортировки и направления.
*   **2.2. Фильтрация/Поиск:**
    *   Добавить поле ввода (`<input>`) для текста фильтра.
    *   Реализовать логику фильтрации данных по значению из поля ввода (можно фильтровать по всем текстовым полям или по выбранным).
    *   Обновлять отображение таблицы при изменении значения фильтра (в реальном времени).
*   **2.3. Пагинация:**
    *   Создать или использовать готовый компонент пагинации.
    *   Реализовать логику разбиения отфильтрованных/отсортированных данных на страницы в `DataService` или компоненте.
    *   Добавить элементы управления для:
        *   Выбора количества записей на странице (например, `select` со значениями 10, 25, 50).
        *   Переключения между страницами (кнопки "Вперед", "Назад", номера страниц).
    *   Обновлять отображаемые данные при изменении страницы или размера страницы.
*   **2.4. Управление колонками:**
    *   Разработать UI для выбора видимых колонок (например, кнопка с выпадающим списком чекбоксов).
    *   Хранить состояние видимости колонок в компоненте.
    *   Динамически генерировать заголовки и ячейки таблицы на основе выбранных колонок.

## 3. Качество кода и Завершение

*   **3.1. Качество кода:**
    *   Проводить рефакторинг по мере необходимости для улучшения читаемости и поддержки.
    *   Следовать принятым стайл-гайдам Angular и TypeScript.
    *   Обеспечить корректную типизацию.
*   **3.2. Асинхронность:**
    *   Убедиться, что загрузка данных действительно имитирует асинхронный запрос с видимой (хоть и случайной) задержкой.
*   **3.3. Тестирование (Опционально):**
    *   Написать базовые юнит-тесты для `DataService` (проверка загрузки, сортировки, фильтрации, пагинации).
    *   Написать тесты для `DataTableComponent` для проверки отображения и взаимодействия.

## 4. Опциональные улучшения (Бонус)

*   **4.1. Дизайн и UX:**
    *   Применить стили (CSS/SCSS) для улучшения внешнего вида таблицы и элементов управления.
    *   Рассмотреть использование UI-библиотеки (например, Angular Material, Bootstrap/ng-bootstrap) для готовых стилей и компонентов (пагинация, меню и т.д.).
    *   Добавить индикаторы загрузки, обратную связь при действиях пользователя.
*   **4.2. Адаптивность:**
    *   Протестировать таблицу на разных размерах экрана.
    *   Применить CSS медиа-запросы или другие техники для адаптации:
        *   Возможно, скрытие менее важных колонок на малых экранах.
        *   Использование горизонтального скролла для таблицы.
        *   Переформатирование отображения строк (например, каждая строка как карточка).
