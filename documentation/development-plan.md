# План разработки: Функциональная таблица данных (с использованием DevExtreme)

Этот план описывает шаги по созданию функциональной таблицы данных в соответствии с требованиями, изложенными в `task-requirements-rus.md`.

## 1. Настройка проекта и базовые компоненты

*   [✓] **1.1. Инициализация проекта:**
    *   [✓] Создать новый Angular проект с помощью Angular CLI (`ng new`).
    *   [✓] **Добавить Angular Material** в проект (`ng add @angular/material`). Выбрать тему.
    *   [✓] Настроить базовую структуру проекта (модули, папки для компонентов, сервисов). Импортировать необходимые модули Angular Material (например, `MatTableModule`, `MatPaginatorModule`, `MatSortModule`, `MatFormFieldModule`, `MatInputModule`, `MatCheckboxModule`, `MatMenuModule`, `MatButtonModule`).
*   [✓] **1.2. Сервис данных:**
    *   [✓] Создать сервис (`DataService`) для инкапсуляции логики работы с данными.
    *   [✓] Реализовать в сервисе метод для получения данных из `data.ts`.
    *   [✓] Имитировать асинхронный запрос с использованием RxJS (`Observable`, `of`, `delay`) со случайной задержкой.
    *   [✓] Определить интерфейс (`interface`) для типизации объектов данных.
    *   [✓] **Подготовить методы в сервисе (или в компоненте) для обработки сортировки, фильтрации и пагинации данных.**
*   [✓] **1.3. Основной компонент таблицы:**
    *   [✓] Создать компонент (`DataTableComponent`) для отображения таблицы.
    *   [✓] Подключить `DataService` для получения данных.
    *   [✓] **Использовать `MatTable` из Angular Material для отображения данных.** Настроить `MatTableDataSource` для интеграции с сортировкой, фильтрацией и пагинацией Material.
    *   [✓] Определить отображаемые колонки (`displayedColumns`).

## 2. Реализация основной функциональности (с Angular Material)

*   [✓] **2.1. Сортировка:**
    *   [✓] **Интегрировать `MatSort`** с `MatTable` и `MatTableDataSource`.
    *   [✓] Добавить директиву `matSort` к таблице и `mat-sort-header` к заголовкам колонок.
    *   [✓] `MatTableDataSource` возьмет на себя основную логику сортировки на клиенте. Убедиться, что кастомные/вложенные поля (как `name.first`) сортируются корректно (может потребоваться кастомная `sortingDataAccessor`).
*   [✓] **2.2. Фильтрация/Поиск:**
    *   [✓] Добавить поле ввода **`MatInput` внутри `MatFormField`** для текста фильтра.
    *   [✓] Привязать значение поля ввода к свойству `filter` у `MatTableDataSource`.
    *   [✓] Настроить `filterPredicate` у `MatTableDataSource` при необходимости для кастомной логики фильтрации (например, по вложенным полям или нескольким полям одновременно).
*   [✓] **2.3. Пагинация:**
    *   [✓] **Интегрировать `MatPaginator`** с `MatTableDataSource`.
    *   [✓] Добавить компонент `<mat-paginator>` в шаблон.
    *   [✓] Настроить опции пагинатора (размеры страниц `pageSizeOptions`).
    *   [✓] `MatTableDataSource` автоматически обработает логику отображения данных для текущей страницы.
*   [✓] **2.4. Управление колонками:**
    *   [✓] Разработать UI для выбора видимых колонок:
        *   [✓] Использовать кнопку (`MatButton`) с иконкой.
        *   [✓] По клику открывать **`MatMenu`**.
        *   [✓] В меню отображать список колонок с **`MatCheckbox`** для управления видимостью.
    *   [✓] Хранить состояние видимости колонок (массив `displayedColumns`) в компоненте.
    *   [✓] Динамически обновлять массив `displayedColumns` при изменении чекбоксов, что автоматически обновит отображаемые колонки в `MatTable`.
