# Требования к задаче: Функциональная таблица данных

**Задача:** Создать "функциональную" таблицу (аналогичную электронным таблицам), где строки можно фильтровать, сортировать, а сама таблица поддерживает пагинацию. Данные для таблицы берутся из предоставленного файла `data.ts`.

## Основные функциональные требования

- [ ] **Сортировка:** Пользователь может сортировать данные по любой колонке (например, кликом по заголовку колонки). Необходимо предусмотреть сортировку по возрастанию и убыванию.
- [ ] **Фильтрация/Поиск:** Должно быть поле ввода для фильтрации/поиска данных по всем или выбранным полям таблицы в реальном времени.
- [ ] **Пагинация:**
    - [ ] Пользователь может выбрать количество записей, отображаемых на одной странице (например, 10, 25, 50).
    - [ ] Пользователь может переключаться между страницами данных.
- [ ] **Управление колонками:** Пользователь может скрывать и показывать колонки таблицы. Необходимо продумать удобный для пользователя способ управления видимостью колонок.

## Требования к реализации

- [ ] **Качество кода:** Акцент на функциональность и качество кода. Код должен быть чистым, читаемым и поддерживаемым.
- [ ] **Асинхронность:** Бэкенд-приложение не требуется, но фронтенд должен имитировать асинхронный запрос данных со случайной задержкой ответа (для эмуляции сетевого взаимодействия).
- [ ] **Источник данных:** Использовать предоставленный JSON-файл (`data.ts`) в качестве источника данных.

## Опциональные требования (Бонусные баллы)

- [ ] **Дизайн:** Привлекательный дизайн. Приветствуются хорошие UI/UX решения.
- [ ] **Адаптивность:** Мобильно-дружественный дизайн. Продумать, как таблица будет выглядеть и функционировать на разных размерах экранов.
